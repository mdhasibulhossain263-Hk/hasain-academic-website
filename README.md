# mdhasibulhossain263-hk.github.io/hasain-academic-website

Personal academic website of **Md Hasibul Hossain** — Civil Engineering graduate,
researcher in sustainable construction materials and environmental assessment.

## Pages

| File | Page |
|---|---|
| `index.html` | About — background, research framework, interests |
| `research.html` | Research — four laboratory projects with figures |
| `experience.html` | Professional experience and assessment projects |
| `portfolio.html` | Design, drafting and GIS portfolio |
| `teaching.html` | Teaching, service, honours, languages |
| `cv.html` | Full curriculum vitae |
| `contact.html` | Contact details and academic referees |
| `404.html` | Page-not-found |

## Built with

Plain HTML, CSS and JavaScript. No frameworks, no build step, no dependencies.
Every `.html` file is complete and can be opened directly in a browser.

- `assets/css/style.css` — all styling, with colour tokens at the top
- `assets/js/main.js` — theme toggle, mobile menu, scroll behaviour
- `assets/figures/` — the nine research diagrams as standalone SVG files
- `assets/cv/` — CV in PDF form
- `_parts/` — source fragments and an optional build script; **not required**,
  the site works without it and the folder can be deleted

## Figures

Figures 2–5 are plotted directly from the data tables of the author's
undergraduate thesis, *Utilisation of Rice Husk Ash (RHA) as Partial Replacement
of Cement for Sustainable Concrete* (Presidency University, 2022).
